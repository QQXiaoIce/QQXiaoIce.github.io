实用图床推荐及使用情况记录

最近一次复查：2026-09-29。当前状态都在下表，实测各站（含每张历史测试图）都能正常加载。

速查表

图床 现状 备注
Hello 图床 强制登录 + 付费 免费别用
SM.MS (s.ee) 正常 老 sm.ms / smms.app 都跳过来；免费，但 API 上传必须带 Key，用来区分用户和存历史记录
Imagehub 正常
Imgurl 正常 域名从 .ink 换成 .org
路过图床 正常 新域名，老 imgse.com 是同一家

下面挨个展开。

Hello 图床

https://www.helloimg.com/

以前挺喜欢用的，速度还快，后来换了老板，又经历改版，再后来就收费了，本来还有 5GB 的免费空间，现在连免费的 5GB 空间也没了。

S.EE 原 SM.MS

https://s.ee/

也算是很稳定的一个，用的人多，插件生态也全。搬过一次家，老的 sm.ms / smms.app 现在都自动跳过来。速度一般，海外节点偶尔抽风，但稳定性可以。

换到新图床地址后传的图：

Imagehub

https://imagehub.cc/

响应快，国内访问顺畅。老接口一直在用，没出过岔子。

Imgurl

https://www.imgurl.org/

免费用户 2G 空间，每天上传次数有限制。域名从 imgurl.ink 换成了 imgurl.org，旧域还能跳但别再贴新链接。

路过图床

https://imgchr.com/

官方域名现在是 imgchr.com。imgse.com 是同一家同一个图库，账号、老图片都还在，只是公开访问切到了新域名——老域名下的 /i/<id> 详情页现在会 403，把域名换成 imgchr.com 就能重新打开。

已经放弃的

  • z4a.net — 域名被抢去做美图站，原图床彻底没了。
  • SM.MS 老 loli 通道 — 图存在，上传接口早就关停。

这篇是个人备忘，每隔几个月回头刷新一次。哪天 SM.MS 也彻底挂了，再来删一删。
